# 翻译准备：分割与排版合并为一步

CRITICAL: 在图片替换完成后，运行 `scripts/prepare_translation.py` 一次。成功退出即完成；不再分别运行分割和排版，不额外回读、统计或人工复查。脚本内部执行必要的文字保全与标签检查。

## 输入、输出与命令

- 输入：书籍目录下的 `书籍名.md`。
- `translate-split/`：按原段落分组的中间文件，默认每文件目标 40000 字符，不强求精确值；超长原段落独占文件。
- `translate-typeset/`：同编号的安全断句文件，供 `fasttrans.py` 翻译。原书文件不变，不自动开始翻译。
- 单个换行不拆原段落；空行用于识别原段落，完整的 `<sup>...</sup>` 不被分到不同文件。

```powershell
python "C:\playground\.codex\skills\pdf-set\scripts\prepare_translation.py" --base-dir "C:\playground\书名"
```

可选参数：`--book-name`、`--input-file`、`--split-dir`（中间目录）、`--output-dir`（最终目录）、`--file-chars`（默认40000）、`--max-chars`（每段目标250）、`--buffer-chars`（默认200）。`--base-dir`、`--book-name`、`--input-file`、`--split-dir`、`--output-dir` 支持同名 `-from` 参数，从UTF-8文件读取首个非空行。

## 断句标准

- 超过目标加缓冲（默认450）才尝试按真实句末断段，选最接近目标的位置。没有可信句界则保留长段，不为长度强拆。
- **括号内部可以断开**，包括长圆括号、方括号和脚注；在其中正常句末分段，不要求括号每段重新配对，不添加新的脚注内容。每段的 `<sup>...</sup>` 仍须完整配对。
- 页码、卷章图注编号、金额和日期保持完整，例如 `p. 254`、`t. II`、`3 fl. 65 kr.`、`oct. 1911`；列表的 `1.` 或嵌套注的 `a.` 不与内容分离。
- 保护法／德／英缩写与OCR空格变体，例如 `par ex.`、`c.-à-d.`、`l. c.`、`e.g.`、`OCF.P`、`W.-C.`、期刊缩写；保护完整姓名、连续首字母、带重音字母、缩略名、头衔和 `v.`，如 `J. M. Charcot`、`Alf. Adler`、`Emmy v. N.`。
- 句界需看右括号、引号、附注之后是否仍接逗号、小写主句或其他续接；短编者标记 `[!]`、`(?)` 不是句末。附注留在锚定词后，标点簇不拆散。Markdown图片、链接、行内代码及URL内部不切分。
- 不把所有缩写或数字后的句号都禁用：它们可能兼作真实句末；例如 `Ics. Certes…`、`4380 cour. Et…` 仍可正常分段。

## 已有翻译的保护

脚本拒绝覆盖非空输出目录。遇到已有输入或译文，不删除目录、不自动重建或强行续译；告知用户旧译文按段号续翻，重新断句会改变段号，需要另目录生成并做专门迁移。用户仅要求更新脚本时，不修改任何已有书籍输出。

翻译准备的唯一命令入口是 `prepare_translation.py`，不提供旧的独立分割、排版入口。

## 脚本维护验证（不是每本书的附加步骤）

修改断句逻辑时运行：

```powershell
python -X utf8 -m unittest discover -s "C:\playground\.codex\skills\pdf-set\scripts\tests" -v
```

测试包含弗一至弗五已识别的500处误断上下文、正常句末反例、长括号可切、长脚注标签、原文保全及拒绝覆盖。规则修复不能靠取消所有分段来通过；新增真实失误应补入回归案例。测试覆盖已知案例，不宣称能穷尽任意语言和OCR错误。
