CRITICAL:
- 本步骤在 OCR 之后、排版成书之前执行；它直接修改 `ocr-result/` 中原有的单页 Markdown 文件。
- 不合并页面，不生成 `起始页-结束页.md`，不调用 `scripts/footnote_continuation.py`。
- 只处理跨页脚注并删除提示符；不得凭空补写、猜测、润色或翻译。若跨页续文被 OCR 漏掉，但在对应原图中清晰可辨，必须依据原图忠实补录。
- `⬆️`、`⬆`、`⬇️`、`⬇` 是 OCR 添加的判断提示，可能属于误判，不能仅凭提示符认定存在跨页脚注。

## 输入/输出

- 输入：`ocr-result/` 中按页码命名的初步 OCR Markdown 文件。
- 输入：`images/` 中同页码的 jpg/jpeg/png/bmp/tif/tiff/webp 图片，用于判断脚注与正文的边界。
- 输出：直接写回相关的 `ocr-result/页码.md`。
  - 未涉及跨页脚注的页面保持不变。
  - 涉及跨页脚注的页面仍保持各自的单页文件和原文件名。
  - 后页的脚注续文追加到脚注开始的前页；后页中已转移的续文删除。
  - 若提示符属于 OCR 误判，可以不转移任何文字，只删除提示符。
  - 处理完成后，相关页中的 `⬆️`、`⬆`、`⬇️`、`⬇` 提示符全部删除。

## 阶段 1：确定目标范围

1. 扫描 `ocr-result/` 中的数字页码 Markdown 文件。
2. 按页码顺序判断跨页承接：
   - 若前页有 `⬇️` 或后页有 `⬆️`，生成两页范围。
   - 若范围末页仍有 `⬇️`，继续向后扩展。
   - 若前页有 `⬇️` 而下一页没有 `⬆️`，但再后面的连续页有 `⬆️`，扩展到该页。
3. 记录每个连续承接范围，供后续逐页判断和修改；不要创建范围合并文件。

## 阶段 2：判断脚注承接关系

对每个目标范围，由 agent 判断是否确实存在跨页脚注。提示符只是待核查线索，不是跨页关系的确定证据。

1. 定位前页带 `⬇️` 的未完脚注，以及后页带 `⬆️` 的脚注续文。
2. 先根据 Markdown 中的文字语义和脚注编号判断承接关系：
   - 确认存在跨页脚注时，确定续文属于哪一条前页脚注。
   - 确认提示符是 OCR 误判时，不移动或删除任何文字，后续只删除提示符。
3. 如果仅凭 Markdown 不知道如何处理，必须查看 `images/` 中与相关页同名的图片，例如用 `12.jpg` 核对 `12.md`；结合原图中的版面位置、字号、脚注编号和页首页尾关系判断后再处理。
   - 若原图中存在清晰可辨的跨页续文而 Markdown 完全或部分漏识别，按原图字符边界逐字补录；这属于修正 OCR 漏文，不属于凭空补充。
   - 若原图模糊、裁切或无法可靠辨认，不得猜测，停止修改该范围并向用户说明。
4. 若跨越多页，按页码顺序收集全部续文，并归入最初开始该脚注的页面。
5. 提示符只用于定位，不属于正文或脚注内容。

查看同名图片后仍无法可靠判断时，停止修改该范围并向用户说明，不能猜测。

## 阶段 3：直接修改单页文件

根据判断结果修改：

1. 确认存在跨页脚注时，将后页 Markdown 中已有的续文，或依据清晰原图补录的漏识别续文，按原顺序追加到前页对应脚注的末尾，使脚注内容连续。
2. 从后页删除已经转移的续文；不得删除或移动后页的正文、其他脚注和其他内容。
3. 对多页续注，将所有续文依次追加到脚注起始页，并从各续页删除已转移内容。
4. 确认提示符属于 OCR 误判时，不转移任何文字，也不改动正文或脚注内容。
5. 无论是否发生文字转移，都删除该范围内所有 `⬆️`、`⬆`、`⬇️`、`⬇` 提示符。
6. 将修改分别写回原来的 `页码.md`，不要改变文件名，也不要把多页内容合并到一个文件。

## 阶段 4：核对

逐个目标范围确认：

- 脚注续文已完整且按顺序并入起始页；原图清晰可见但 OCR 漏掉的续文已忠实补录。
- 对 OCR 误判的提示符，只删除了提示符，没有转移或删除文字。
- 续页只删除了已转移的脚注续文。
- 正文、其他脚注和无关内容未被改动。
- 所有跨页提示符均已删除。
- 没有生成 `起始页-结束页.md` 或其他合并文件。
